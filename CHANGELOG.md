# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [0.0.1] - 2026-10-06

### Added
- **Project Structure:** Inicialización del repositorio de la Landing Page utilizando Vite[cite: 2].
- **Dependencies:** Integración de los paquetes `@primeuix` y `@primeicons` para el diseño de la interfaz de usuario[cite: 2].
- **Routing:** Implementación inicial de la barra de navegación para desplazar al usuario a través del Landing Page.
- **Hero Section:** Adición de la sección principal (Hero) con la propuesta de valor de **Al ToDu** ("Domina tu tiempo con Inteligencia Artificial") e implementación del llamado a la acción (CTA).
- **Styles:** Archivo `style.css` base con la paleta de colores de marca y estilos estructurales para el Hero Section y la barra de navegación.
- **Documentation:** Se añadieron los diagramas de arquitectura C4 (Components) en la carpeta `docs/c4/` utilizando PlantUML (`components-frontend.puml`)[cite: 2].

### Design notes
- El diseño visual del Hero Section implementa el **patrón Z** para dirigir la lectura y fomentar la conversión, guiando el ojo desde el logotipo hacia el botón de acción principal.
- Se ha estructurado el HTML aplicando los principios de composición **CRAP** (Contraste, Repetición, Alineación y Proximidad) para garantizar la claridad visual.
