# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-11-02

### Added

- Major production version (`v2.0.0`) of the **AI-ToDu** platform following Domain-Driven Design (DDD) and Clean Architecture principles.
- Complete implementation of core bounded contexts: **IAM** (Authentication & Role Access), **Warehouse & Inventory** (SKUs, Quarantine, Stock Alerts), **Sales & Billing** (POS Transactions, IGV Calculation & Automatic Stock Sync), and **Logistics & Dispatch** (Shipment Manifests & IoT Telemetry).
- Unified responsive presentation layer with localized bilingual support (`en_US` and `es_419`) and WCAG accessibility compliance.
- Integrated Mock RESTful API (`json-server` / `db.json`) and cloud deployment configuration for Microsoft Azure App Service.

## [1.0.0] - 2026-10-23

### Added
- Stable production version (`v1.0.0`) of the **AI-ToDu** website and landing page platform.
- Complete responsive architecture implementing clean web design, interactive navigation, and localized support (`en_US` and `es_419`).
- Production-ready configuration for deployment and seamless integration with backend services.
